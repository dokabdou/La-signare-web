/!\ When something doesnt load with the page set it as an observable/subject(if it will be updated), like products in AdminComponent and NavbarComponent
on admin when the page is reloaded the products disappear : ReplaySubject =>
The issue is that products$ is a Subject that doesn't replay values. When the component subscribes with the async pipe, if the value was emitted before subscription, it won't receive it. Use ReplaySubject instead
